# Creatiobs Creative Academy — Frontend

A premium multi-page frontend built with only HTML5, CSS3 and vanilla JavaScript.

## Pages
- `index.html`
- `courses.html`
- `placements.html`
- `portfolio.html`
- `about.html`
- `contact.html`

## Folders
- `css/style.css` — complete design system and responsive styles
- `js/script.js` — navigation, carousel, filtering, modal, form validation, counters and scroll reveal
- `assets/images/` — replaceable image area
- `assets/reference/` — supplied reference screenshots, kept for design reference

## Image replacement
The website intentionally uses styled placeholders such as:
- ADD HERO IMAGE
- ADD COURSE IMAGE
- ADD MENTOR IMAGE
- ADD PROJECT IMAGE
- ADD LOGO
- ADD PLACEMENT / STUDENT DATA

Replace these with approved client assets before launch. No fake logos, testimonials, placement percentages or salary claims have been added.

## Run
Open `index.html` directly in a browser. No build step is required.

The Google Fonts link improves typography when internet access is available; the site has fallback system fonts if it is not.


## GitHub Pages deployment

This package has `index.html` at the repository root.

1. Extract the ZIP.
2. Upload/commit the **contents** of this folder to the root of your GitHub repository (not the outer folder itself).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for deployment to finish and open the URL shown in Settings → Pages.

Keep these paths unchanged: `index.html`, `css/style.css`, `js/script.js`, and the other HTML pages. CSS and JavaScript are intentionally separated and use relative paths supported by GitHub Pages.
