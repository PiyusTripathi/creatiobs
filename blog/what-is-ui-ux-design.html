What Is UI/UX Design?

By Creatiobs Team / Published Oct 14, 2026 / Updated Oct 14, 2026

UI/UX BASICS

UX design focuses on how a product works for users. UI design focuses on how the interface looks and behaves. Together, they help create apps and websites that are clear, useful and pleasant to use.

What beginners learn

Beginners usually start with user flows, wireframes, interface patterns, visual hierarchy, spacing, typography, Figma and clickable prototypes.
